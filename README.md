# 🎮 Projeto Teste Unity

Este repositório contém um projeto de um jogo teste desenvolvido em 2021.

Serve como base para experimentação, aprendizado e testes com a Game Engine Unity.

> ⚠️ Este projeto foi desenvolvido com **Unity 2021.3.24f1**. Recomenda-se utilizar a mesma versão para evitar problemas de compatibilidade.
